# Kalingalinga valuation-gap methodology

This section explains the valuation gap analysis in formal academic style.

## Valuation Gap Analysis for Kalingalinga

The valuation gap in the Kalingalinga study area was evaluated by comparing the properties recorded in the current valuation roll with the properties identified through spatial analysis of building footprints. The valuation roll for the pilot area contained 12 recorded properties. To assess whether additional properties were missing from the valuation records, the mapped building footprints in the study area were compared with the recorded property locations using spatial overlay and property matching techniques.

The results showed that the study area contained 19 mapped properties, while only 12 were present in the existing valuation roll. The difference between the total mapped properties and the recorded properties was 7 properties, which represents the valuation gap in the study area. These additional properties were not represented in the valuation roll and therefore were excluded from the current property tax assessment base.

This finding indicates that the available valuation records do not fully capture the actual property stock in the Kalingalinga area. The absence of these properties from the tax database may result in an underestimation of the rateable property base and potential revenue losses for the local authority. The use of GIS-based property identification therefore provides a practical approach for improving property roll completeness and supporting more accurate property valuation and municipal revenue collection.
